# Pomotime
> Improvements in progress, this version of Pomotime is NOT final so it is recommended to use [the hosted version](https://nullclock.github.io/Pomotime/), where updates are automatically reflected.

Pomotime is an ultra-simplified minimalistic pomodoro timer designed to enhance your workflow and make focus easier and simpler than it's ever been before.
All of Pomotime's code is in a single HTML file, making it easy to host yourself or even run locally. 
(you can download the HTML file and use it in your browser without even hosting it!)

You can also use the readily-available version of Pomotime at my Github Pages site linked in the description and [here](https://nullclock.github.io/Pomotime/)
